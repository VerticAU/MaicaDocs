# General

These pages cover each part of an Appointment, from its basic details through to its Location, Schedule and Summary. The information on each page applies to both the Standard and Legacy experiences. Where the two experiences look different, screenshots of both are shown side by side.

{% hint style="info" %}
To see how each experience works from start to finish, see [Standard Experience](../standard-experience.md) and [Legacy Experience](../legacy-experience.md).
{% endhint %}
