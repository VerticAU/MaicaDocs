# Create a Shift

## How do I create a Shift?

A quick and efficient way to create a [Shift](../../getting-started/maica-key-concepts/shift.md) is directly through the Maica [Planner](../../the-planner/planner-overview.md). Maica has an interactive mechanism where you can drag and release your mouse on the Planner to prompt the creation of a Shift.

{% hint style="info" %}
Creating a Shift depends on which [View](../../the-planner/planner-views-and-modes/) you are in within the Planner. You need to be in the `Roster` or `Shift` View to create a Shift, otherwise you will [create an Appointment](../../appointments/create-an-appointment/).
{% endhint %}

{% hint style="info" %}
You can also create a Shift through the Planner Quick Action. To learn more, see [Create New Appointment](../../the-planner/planner-actions/create-new-appointment.md).
{% endhint %}

## Standard and Legacy experiences

Maica offers two experiences for creating and managing Shifts. The experience you see depends on your organisation's settings. If your screen does not look like the one described in these pages, contact your administrator.

| Experience                                    | How a Shift is created                                                                                                                        |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| [Standard Experience](standard-experience.md) | A single screen with two steps. Each detail is edited in place, and a Summary shows the Shift Services that will be delivered before you save |
| [Legacy Experience](legacy-experience.md)     | A series of stages, each covering one part of the Shift, completed in turn before the Shift is confirmed                                      |

The pages under [General](general/) cover each part of a Shift, and apply to both experiences.

{% hint style="info" %}
In both experiences, the details you are asked for are determined by the Maica Settings. For further information, see [Service Management](https://app.gitbook.com/s/9selzjEx6KX7RYEawAVr/settings/service-management) in the Administration Guide.
{% endhint %}
