# Shift View

## What information does the Shift View display?

The Shift View is an overview of all `Shift` information.

By default, Shift View shows **standalone Shifts only**, meaning Shifts that do not belong to a Roster. Use the **Show Roster Shifts** filter to include Roster Shifts in the view as well.

{% hint style="info" %}
If a Shift you expect to see is missing, check whether it belongs to a Roster. Turn on **Show Roster Shifts** to include it here, or open Roster View to work with that Roster directly.
{% endhint %}

{% hint style="info" %}
You have the option to display both unfilled `Shifts` and `Shifts` with allocated `Resource(s)`. To learn more, see [Planner Management](https://app.gitbook.com/s/9selzjEx6KX7RYEawAVr/settings/planner-management) in the Administration Guide.
{% endhint %}

## Calendar Mode

On Calendar Mode, Shift View will display your Planner with the above information within a grid based on the days and hours of the selected period.

{% hint style="info" %}
A Shift shown with a red outline is an unfilled Shift. An unfilled Shift is any Shift that does not have the required number of Resources allocated.
{% endhint %}

## Timeline Mode

On Timeline Mode, Shift View will organise your Planner by `Shift(s)`. This will display all of the `Shift(s)` in chronological order.

{% hint style="info" %}
The details displayed on each Shift cell are configurable. To learn more, see [Planner Management](https://app.gitbook.com/s/9selzjEx6KX7RYEawAVr/settings/planner-management) in the Administration Guide.
{% endhint %}

### Group By indicators

If you use the `Group By` Planner Action, **Maica** will show helpful indicators on your Planner to inform you of how many unique `Shift(s)` you have at any given time.

For example, where the Planner is grouped by `Location`, **Maica** shows how many unique `Shifts` fall within each time slot.

The colours of the numbers indicate the filled status of the Shift(s), as per below:

* **Green**: Shifts filled with the required number of Resource(s).
* **Yellow**: Shifts partially filled with the required number of Resource(s).
* **Red**: Shifts not filled with any Resource(s).

{% hint style="info" %}
An unfilled Shift is any Shift that does not have the required number of Resources allocated.
{% endhint %}
