# Group By

## How do Group my information on the Planner?

On the Planner, you can group your information in order to make it easier to visualise related items together. For example, in [Shift View](../planner-views-and-modes/shift-view.md), you can order Shifts(s) by Location, which improves organisational clarity and planning.

To begin, simply begin by clicking the `Group By` button, as shown below.

<figure><img src="../../.gitbook/assets/group by button.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
This function is only available in Timeline Mode.
{% endhint %}

Once selected, the custom `Group By Field Selector` module will display, as shown below.

<figure><img src="../../.gitbook/assets/Screenshot 2024-09-23 at 3.56.51 pm.png" alt=""><figcaption></figcaption></figure>

It is here you can select which field you wish to organise your information by.

{% hint style="info" %}
As I have selected the `Group By` action from `Shift View`, the available fields are `Appointment/Shift` fields, as shown above. This is because `Shift View` organises the Planner by `Shift`. If you were to select the `Group By` action from `Accomodation View`, these fields would be catered to `Accomodations`.
{% endhint %}

After selecting a field, click `Select` to finalise. Below, I have chosen to Group my Shifts by `Location`.

<figure><img src="../../.gitbook/assets/Screenshot 2024-09-23 at 3.58.18 pm.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
[Roster View](../planner-views-and-modes/roster-view.md) is already grouped by `Location` when it opens, since a Roster covers a single Location and the lanes are the point of that view.
{% endhint %}

{% hint style="success" %}
When you group your Planner, **Maica** also shows indicators telling you how many unique `Shift(s)` fall within each time slot, colour-coded by how well they are filled. To learn more about these indicators, see [Shift View](../planner-views-and-modes/shift-view.md).
{% endhint %}
