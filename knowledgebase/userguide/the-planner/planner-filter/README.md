# Planner Filter

## What is the Planner Filter?

The Planner Filter in **Maica** is a tool that allows users to refine and customise the information displayed on the Planner. By selecting specific criteria, you can narrow down the view to focus on relevant information and data. The Planner Filter ensures that users can efficiently manage and organise Appointments, Shifts, Resources, and Participants based on the selected filters.

## Where do I find the Planner Filter?

The Planner Filter is located on the far left hand side of the Planner menu, as shown below:

<figure><img src="../../.gitbook/assets/filter location.png" alt=""><figcaption></figcaption></figure>

Once you have selected the Filter, **Maica** offers two filtering options. These are:

1. [Basic Filters](basic-filters.md)
2. [Advanced Filters](advanced-filters.md)

For further in-depth information on each filtering option, please refer to the associated page.

At the top of the filter panel, **Your Filters** lets you pick a saved filter, or save the current settings so you can return to them later. Saved filters apply on both the Basic and Advanced tabs. See **Saved Planner Filters** for how to save, find, share and delete them.

## Planner Filter Applied Notification

When a Filter of any type is applied in the **Planner**, whether it's a **Basic** or **Advanced** filter, the **filter icon** circled above will turn **Yellow**.

This provides a visual cue that a filter is currently active. To reset the view, simply click the filter icon and clear the selected filters.

{% hint style="success" %}
If the Filter is open but nothing has been applied, it will appear **Green**.
{% endhint %}

## Where the Planner starts

The Planner opens with the filter settings stored in your browser. Where nothing is stored, it starts from the **Org Default** saved filter when your administrator has chosen a **Default Planner Filter** in the Planner settings, and from Maica's built-in defaults otherwise.

Users who do not hold the **Manage Filter** permission always start from the **Default Planner Filter**.

{% hint style="info" %}
The **Appointment Resource Status** filter starts from the **Default Appointment Resource Status** setting. Where that setting is blank, the filter starts with all statuses. See **Basic Filters** for the full list of filters.
{% endhint %}
