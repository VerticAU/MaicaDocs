# Support at Home

These settings determine how Maica manages Support at Home features and their function throughout the application. Please refer to the below table for more information on each setting:&#x20;

| Setting                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Service Provider ID**    | The registered provider ID required to retrieve Care Management Budget data. This is a mandatory field and must be entered before budget details can load.                                                                                                                                                                                                                                                                                                                                                                      |
| **Care Management Budget** | <p>Displays a read-only summary of the pooled Care Management funds as reported by Services Australia, including Budget ID, Budget Type, Start Date, End Date, Total, Used, and Available amounts. <br><br><em>The budget reflects the most recent sync time, shown in the grey info box. Use the refresh icon to manually retrieve the latest data from Services Australia.</em> <br><br>To learn more about the Care Management Budget Sync, <a href="../support-at-home/care-management-budget-sync.md">click here</a>. </p> |
